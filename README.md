# БурмалСТРОЙ

Система для подачи и обработки заявок о неисправностях.

## Возможности
- Подача заявки (ФИО, комната, тема, описание) с клиентской и серверной валидацией
- Роли: студент, сотрудник, специалист, заведующий
- Смена статуса заявки (только специалистом): новая → в работе → выполнена / отклонена
- История изменений по каждой заявке
- Уведомления: внутренние + e-mail (по желанию пользователя)
- Сводка за неделю (с выбором периода, фильтрами по комнате и статусу)
- Визуализация: распределение по статусам, по дням, топ комнат, среднее время

## Требования
- Node.js ≥ 18
- npm

## Быстрый старт

```bash
cd backend
cp .env.example .env
npm install
npm run seed     # создать демо-пользователей
npm start
